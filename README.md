# 🏙️ CityForge — Construtor de Cidades, Ruas e Viadutos

Aplicativo interativo de simulação urbana para construção de ruas, avenidas, rodovias, viadutos, pontes, túneis e zoneamento urbano.

## 🚀 Como Publicar na Vercel

### Opção 1: Via Vercel CLI (Direto do Terminal)
1. Abra o terminal na pasta do projeto:
   ```bash
   cd C:\Users\User\.gemini\antigravity-ide\scratch\city-builder
   ```
2. Execute o comando da Vercel:
   ```bash
   npx vercel
   ```
3. Siga as instruções no terminal (faça login na sua conta Vercel). O link público será gerado instantaneamente!

---

### Opção 2: Pelo Dashboard da Vercel (GitHub)
1. Crie um repositório no seu GitHub e envie os arquivos desta pasta:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - CityForge"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   git push -u origin main
   ```
2. Acesse [vercel.com](https://vercel.com) e clique em **"Add New..." -> "Project"**.
3. Importe o repositório criado.
4. Clique em **Deploy** (não precisa alterar configurações de build, é um app estático pronto).
